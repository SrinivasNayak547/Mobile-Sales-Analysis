# 📱 Mobile Sales Analysis Dashboard | Power BI

## 📌 Project Overview
The Mobile Sales Analysis project is an interactive Power BI dashboard designed to analyze mobile phone sales performance. It provides valuable insights into total sales, revenue, transactions, customer behavior, and sales trends across different brands, cities, and time periods.

## 🎯 Project Objectives
- Analyze overall mobile sales performance.
- Track total revenue and quantity sold.
- Identify top-performing mobile brands and models.
- Analyze customer purchasing trends.
- Compare sales across different cities and payment methods.
- Monitor monthly and daily sales trends.

## 🛠️ Tools & Technologies
- **Power BI** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and KPIs.
- **Excel** – Data source and preprocessing.

## 📊 Dashboard Features
- Total Sales Overview
- Total Quantity Sold
- Total Transactions
- Average Selling Price
- Monthly Sales Trends
- Brand-wise Sales Analysis
- City-wise Sales Performance
- Payment Method Analysis
- Customer Ratings Analysis
- Day-wise Sales Trends

## 📈 Key Insights
- Identified top-performing mobile brands and models.
- Analyzed monthly sales growth and fluctuations.
- Compared sales performance across different cities.
- Evaluated customer preferences and payment methods.
- Explored overall revenue and quantity trends.
